# Cybrixen room format (UNRELEASED/current format — from Command Injection and Event Log - Ransomware)
Each room = 3 files in a folder: `<slug>.php` (theory + task shell), `<slug>-practical.php` (self-contained interactive HTML lab: dark theme, tutorial button, description, tool/log viewer; flag format CBX{...}), `<slug>-answers.csv` (header `# FILENAME: <slug>-answers.csv`; rows `taskN,qN,answer`).
Theory .php sections: 1 $room_config (id,title,description,icon FontAwesome,banner,difficulty Beginner/Intermediate/Advanced,estimated_time,prerequisites[],learning_objectives[]); 2 $answers_file; 3 $room_tasks sidebar [task1 Introduction, ... taskN Practical, Conclusion]; 4 $js_config (storage_key, instagram_takeaways[4]); 5 $task_questions_data (task1: q0 'Type "yes"'; content tasks have 2-4 short-answer Qs each; practical task has flag Q; last task: 'Type "complete"'); 6 $task_contents[n] HTML heredocs with tables, code blocks, inline SVG diagrams (with comment explaining teaching purpose).
LEARNING room (e.g. Command Injection, ~22KB theory, 7 tasks: Introduction, 3-4 concept tasks, Practical, Conclusion; 50 min; practical ~18KB simulated vulnerable tool).
CHALLENGE room (e.g. Event Log - Ransomware, ~10KB theory with only 3 tasks: Introduction, one big Challenge task with ~9 investigative Qs ending in a CBX{} flag, Conclusion; practical is large ~80KB multi-panel log analyser/tool with tabs per log source, filter bar, realistic data; 60 min Intermediate).
Released-site challenge examples: impossible-travel-vpn, phishing-email-investigation, vpn-brute-force-investigation, malware-detection-drive-by, suspicious-powershell-execution, credential-dumping-investigation.
